# images 폴더

초대장에서 사용하는 이미지를 이 폴더에 넣어주세요.
빌드 시 `public/` 아래 파일은 그대로 배포됩니다.

## 필요한 파일명

| 파일명 | 용도 | 권장 비율 |
| --- | --- | --- |
| `hero.jpg` | 메인(히어로) 배경 사진 | 세로형 (예: 1080x1920) |
| `divider-1.jpg` | 인사말 아래 중간 배너 | 가로형 (예: 1200x800) |
| `divider-2.jpg` | 카운트다운 아래 중간 배너 | 가로형 (예: 1200x800) |
| `og-thumbnail.jpg` | 카카오톡/SNS 공유 썸네일 | 1200x630 |

- 이미지가 없으면 해당 영역은 배경색으로 표시됩니다.
- 로딩 속도를 위해 WebP 또는 적절히 압축한 JPG 사용을 권장합니다.
